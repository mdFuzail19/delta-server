# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

**Do NOT open a public GitHub issue for security vulnerabilities.**

Instead, please email us at: **opensource@zepto.com**

### What to include

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

### Response timeline

- **Acknowledgement:** Within 48 hours of receipt
- **Initial assessment:** Within 5 business days
- **Fix timeline:** Depends on severity; critical issues will be prioritized

### Scope

The following are in scope:

- Code in this repository (Lambda handlers, IaC templates, utilities)
- Dependencies declared in `package.json`
- Infrastructure-as-Code configurations (`template.yaml`)

The following are out of scope:

- Issues in third-party services (AWS, CloudFront, DynamoDB)
- Issues that require physical access to infrastructure
- Social engineering attacks
